# TECHIES COMMUNITY — Telegram Setup Checklist

## Before creating rooms

- [ ] Confirm Option B naming standard.
- [ ] Confirm the community owner and a backup admin.
- [ ] Prepare a restricted external location for documents, tasks, calendar, finance, and KPI records.
- [ ] Decide which rooms will be public and which will use private invite links.
- [ ] Create an access register from `operations/access-register-template.csv`.
- [ ] Create a test Telegram account or ask a trusted non-admin to test onboarding.

## Phase 1 — Foundation

- [ ] `📢 Announcements` — `techies_announcements`
- [ ] `☕ Lounge` — `techies_lounge`
- [ ] `📚 Knowledge Base` — `techies_knowledge_base`
- [ ] `📚 Resource Library` — `techies_resource_library`
- [ ] `💬 Community Feedback` — `techies_community_feedback`
- [ ] `🆘 Help Desk` — `techies_help_desk`
- [ ] Set posting permissions for Announcements, Knowledge Base, and Resource Library.
- [ ] Enable Topics in Lounge, Help Desk, and Community Feedback where useful.
- [ ] Pin the rules, directory, and room-specific purpose posts.
- [ ] Test every invite link in a non-admin browser/session.

## Pre-invite test

- [ ] New member sees Announcements first.
- [ ] Rules confirmation and access request work.
- [ ] Tier 2 approval leads to Lounge access.
- [ ] Tier 3 request requires a project/role and review date.
- [ ] Tier 4 rooms do not appear in public navigation.
- [ ] Bot permissions match `bot-permissions.md`.
- [ ] A manual fallback exists for every automated workflow.
